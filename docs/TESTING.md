## 真实跨应用验证步骤

先将应用放到固定路径启动，进入菜单栏 → 设置 → 前往授权，在「隐私与安全性 → 辅助功能」开启 HoldTranslate。回到设置检查状态。不要给屏幕录制权限。

在设置中点击「准备语言包」，接受 macOS 的下载确认。等待完成。回到原应用，选中下列测试文本：

- English: This is a beautiful day to learn something new.
- 简体：今天的天气很好，我们一起出去散步吧。
- 繁體：今天的天氣很好，我們一起出去散步吧。
- 日语：今日はとても良い天気です。
- 单词：hello

先验证先选中再按 ⇧⌘T；再按住 Option 拖动划选并松开鼠标。Option 与应用选择行为冲突时切换 Control / Option+Command。监听器从不吞掉原快捷键，兼容快捷键也可能触发原应用同名命令。

## 不确定性与边界

- AX 是应用提供的接口，不能保证任意网页渲染器、PDF、游戏或安全控件可读。
- 繁体与日语纯汉字短词存在语言歧义；短词依据系统置信度判断，低置信度拒绝。
- 单元测试通过不等于应用权限、语言模型和实际跨应用交互通过。
- 不提供假译文、联网备用翻译或无提示的剪贴板备份操作。
