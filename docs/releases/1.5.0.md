### 新增朗读
- 原文、译文前各增加一个喇叭，按各自语言使用 macOS 系统声音朗读。
- 在该段选中单词或短语后点击，只读选中的内容；没有选区时朗读整段。
- 播放时显示停止图标，再点一下停止。点击另一侧切换朗读；关闭气泡或开始新翻译时停止，避免声音叠加。
- 原文现在也可以划选。长原文可在摘要区域内滚动，方便选择后面的单词。

使用系统语音在本机合成，不需要麦克风权限、第三方 API 或付费语音服务。语音与翻译语言包分别管理；缺少声音时会提示前往系统设置下载。
