HoldTranslate 正式更名为 **译泡 · LingoWisp**。

> 选中文字，译文就在旁边。

- 更新应用显示名、设置标题、菜单栏提示、退出菜单、气泡标识和版权信息。
- 安装包改为 `LingoWisp.app`，Xcode 工程与 scheme 改为 `LingoWisp`；GitHub 仓库更名为 `Yikessa24/LingoWisp`，原仓库历史与 Release 保留。
- 沿用原应用标识与偏好设置，保留现有快捷键。按住 Option 划选及选中后按 ⌥D 两种方式继续使用。
- 本版只做更名，不改变翻译、译文选择、拖移或圆形粒子消散行为。

### 安装与升级
1. 下载并解压 `LingoWisp-1.4.1-macOS.zip`，将 `LingoWisp.app` 放到固定位置（例如 `~/Applications`）。升级前退出旧版 HoldTranslate，避免保留两个可启动副本。
2. macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel。首次使用需要下载系统翻译语言包。
3. 更名和重新签名后，如提示未授权，请在系统设置 → 隐私与安全性 → 辅助功能中移除旧条目，再添加新路径的 `LingoWisp.app`。

### 验证与限制
- universal Release 构建、应用显示名/版本/执行文件/原标识核对、ZIP 完整性与签名完整性校验通过。
- 已安装至新路径，实际设置界面确认名称、介绍语、保留的快捷键与辅助功能已授权。此前通过的翻译、手势、复制和动效测试未重复运行。
- 当前使用 ad-hoc 签名，尚未使用 Developer ID 签名或公证；其他 Mac 可能被 Gatekeeper 拦截，不能保证直接启动。无需关闭系统安全保护。
- 微信朋友圈等不公开辅助功能选区的界面仍可能无法翻译，兼容问题未在本版修改。
