HoldTranslate 是一款 macOS 菜单栏划词翻译应用，使用 Apple Translation 在设备端翻译，无账号、无翻译历史。

### 本版新增
- 气泡内的译文可直接划选，按 ⌘C 或右键复制选中部分，⌘A 全选；顶部按钮可复制完整译文。
- 气泡出现时不抢键盘焦点，点击译文后即可使用复制快捷键。

### 当前功能
- 按住 Option 划选触发翻译，支持系统三指拖移选词。
- 先选中文字再按 ⌥D 翻译，快捷键可在设置中自定义。
- 气泡持续显示，可拖动顶部避开内容，支持三指拖移；点击 × 或在气泡内双指右滑关闭。
- 关闭时右侧先碎裂，圆形粒子向右飘散，约 1.4 秒完成；开启「减少动态效果」时使用短淡出。
- 支持自动中文与外语互译、手动目标语言、长译文滚动及原文摘要。

### 下载与使用
1. 下载 `HoldTranslate-1.4.0-macOS.zip` 并解压，将应用放到固定位置（如 `~/Applications`）。
2. 需要 macOS 15 或更新版本；安装包同时支持 Apple Silicon 和 Intel。本次实际运行验证环境为 macOS 26.6.2。
3. 首次运行在设置中授权「辅助功能」，并按系统提示准备所需翻译语言包。
4. 更新或移动应用后，如应用仍提示未授权，请在系统辅助功能列表移除旧条目，再添加当前路径的应用。
